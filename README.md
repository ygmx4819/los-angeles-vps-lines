## 洛杉矶机房为什么一直被抢，也一直被人买错

洛杉矶对国内用户的价值其实很朴素：一是跨太平洋海缆密度高，去亚洲的物理距离短，理论上能做到 150ms 上下的往返延迟；二是这里线路种类最全，从国际 BGP 到 CN2 GIA、联通 9929、移动 CMIN2，几乎所有中国方向优化方案都能在同一个机房找到。

问题出在第二点上。选择多，意味着买错的方式也多。

一个常见误区是拿"带宽数字"当质量标准。看到 10Gbps 端口就以为比 1Gbps 的强，其实端口大小只在跑满的时候有意义，日常访问中国用户的体验，取决于回程走的是哪条骨干。另一个误区是只看 CPU 和内存，结果买了台 EPYC 9005 的高配机器，回程绕道美国东岸再转回国，晚高峰照样卡。

| 电信 CN2 GIA | AS4809 | 电信骨干最高优先级，三网回程都走它，晚高峰丢包低 | 带宽成本最高，同配置价格通常最贵 |

| 国际 BGP | telia / zayo / cogent 等 | 价格低、带宽大、流量多 | 不做中国方向优化，回国路径不可控 |

一句话的取舍：**主要用户在国内，优先 Pro（CN2 GIA）或 EB（CMIN2）；主要用户在国外，别为线路多花钱，直接买国际线路那档。**

## 下单前值得确认的几件事

**流量按双向计算。** 官方对这批套餐的说明是入站和出站都计入月度流量。如果你的业务是视频分发或镜像同步，实际可用量会比标称值缩水，预算要留出余量。

**超量不停机，只限速。** 三条线都是流量用完后降到指定带宽继续跑，Pro 系列最低降到 4Mbps，T1 能保住 100–500Mbps。这个设计对怕被突然关机的人很友好，但 4Mbps 基本只能维持 SSH 和轻量网页。

**免费换 IP 有条件。** 洛杉矶的 Pro 和 EB 系列在符合条件时可以先申请免费更换 IPv4，有 15 天的时间间隔限制；超出免费范围的情况通常按次收费（约 5 美元一次）。具体条款以官网说明为准，买之前值得读一遍。

**AS3 平台官方自己提示过还在持续优化阶段**，磁盘性能和 SLA 可能低于成熟平台。这不影响 CN2 GIA 线路本身的质量，但如果你要做对 IO 敏感的数据库业务，建议先用最低档测试再决定要不要上量。

**库存波动快。** 洛杉矶的套餐经常一放出来几天就没了，尤其是低价档和 AN5 平台。看到列表里某档显示缺货，不代表下架，通常只是这一轮卖完了。

**流媒体解锁不做保证。** 原生美国 IP 在多数套餐上实测能解锁 Netflix、YouTube、Disney+ 这类服务，但商家明确不做承诺，风控策略随时会变。如果你的核心需求就是这个，别把它当成合同条款。

## 常见问题

**洛杉矶和香港选哪个？**

香港到国内延迟通常在 20–40ms，洛杉矶在 150ms 上下，这个差距对延迟敏感的应用（实时交互、游戏加速）是决定性的。但香港同等级线路的价格通常是洛杉矶的两到三倍，流量额度还更小。做网站、看视频、跑批量任务，洛杉矶够用；做实时业务且预算充足，再考虑香港。

**$10.90 那档真的能用吗？**

1核 2GB/20GB SSD/1TB 流量，跑一个日 PV 三五千的 WordPress 站点没问题，跑编译或数据库就吃力了。它的意义是把 CN2 GIA 的入场门槛压到十美元级，而不是给你一台全能机器。

**需要额外买高防吗？**

只有确实被打过才需要。DMIT 有一条 Premium Secure 产品线，在回程保住 CN2 GIA 的前提下，用 Cloudflare Magic Transit 做入站清洗，测试 IP 是 45.88.194.155。普通建站没必要为这个付费。

**买完能升级配置吗？**

可以在控制面板里升级到更高档位，补差价即可，但降级通常不支持。如果对配置没把握，先用低档跑一两周再升，比一上来买顶配更稳。

**能装 Windows 吗？**

这些套餐都是 KVM 虚拟化，Windows 需要自己解决授权和驱动，官方主要以 Linux 模板为主。真需要 Windows 环境，建议先和客服确认，别默认可以。
